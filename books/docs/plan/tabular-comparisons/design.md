# 对比类论述表格化：迭代设计

> **状态：未开工**——本文是设计文本；正文尚未改动。
>
> 软件：bookwright — 源码分析成书工具 v0.1
> 版本：v0.2-dev
> 定位：**为什么有些论述必须换成表格**——并列比较用散文写为什么读不快、判据怎么定、哪些门禁
> 会因此受影响。动作与验收看同目录 `plan.md`。

---

## 1. 问题

书里有一类论述的语义是**并列比较**：两个版本的差异、几个参数的取舍、升级前后的行为对照。
现在它们写成长段落，读者要把「A 这样、B 那样」在头脑里对齐才能比。这类内容表格天然适合：

| 读者要做的动作 | 散文 | 表格 |
| --- | --- | --- |
| 找某一维度在某一边的取值 | 逐句扫描 | 定位行 × 列 |
| 确认两边是否同一量纲 | 回读上下文 | 表头即约定 |
| 发现缺失项 | 容易漏 | 空格可见 |

本项目已有一条硬约束与此相关：表格必须能在**三个出口**（HTML、PDF、EPUB）都正常排布，
且 `content_depth`／`readability`／`structure` 的判据不能因为换了呈现形式而变松。

## 2. 目标与非目标

**目标**：把「并列比较」这一类论述改为表格，且三个出口的排版、门禁结论与阅读体验都不变差。

**非目标**：不把叙述性内容表格化（因果、时序、论证链不属于并列比较）；不改表格样式与字号；
不为凑数量造表；不动既有的 ASCII 图（那不是表格）。

**硬约束**：表格行必须同一维度、列数 ≤ 5（超出宽度预算）；单元格不得塞整段散文；
表格前后各有一句引导与结论，避免"表格孤岛"。

## 3. 判据

| 判据 | 怎么判 |
| --- | --- |
| 只换呈现不换内容 | 改写前后的事实条目逐条对应，无新增断言、无丢失取值 |
| 三个出口都成立 | PDF/EPUB 里表格不跨页断行错位；交付校验（PDF、EPUB 两侧）全绿 |
| 判据不放松 | `content_depth`（前向引用/术语/摘录）、`readability`（句长/密度）、`smart`（图示覆盖）结论与改动前一致 |
| 可读性不降 | `readability` 的指标落在原区间；每张表有引导句与结论句 |

## 4. 风险与取舍

- **表格在 EPUB 上的窄屏**：4–5 列在手机上会横向压缩，需要列宽策略（首列固定、余列自适应）；
  试点阶段先看 3 列表。
- **判据口径**：`readability` 按句子度量，表格单元格不是句子；改写后该章句子数会下降，
  若有按句计数的阈值，需确认是"按正文段落"而非"按全章字符"。
- **回退**：每处改写独立提交，回退单处不影响其它；表格样式改动单独一笔，便于定位出口问题。
