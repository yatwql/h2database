# 图注与章节范围的单一来源：实施计划

> 软件：bookwright — 源码分析成书工具 v0.1
> 版本：v0.1
> 定位：**本次整改的动作与验收**——改哪些文件、怎么证明结论不变、怎么回退。
> 设计理由看同目录 `design.md`。

---

## 1. 前提

- 只搬"形状"，不动"判据"：阈值、词表、桥接规则、编号规则、输出文案全部保持现状。
- 等价性由现有用例背书：改完跑一次全量门禁与快档用例，任何一条结论变化都视为回归。
- 章节范围从 `book.toml` 推导，配置为空时退化为空集而不是报错。

---

## 2. 动作

1. `lib/_mdutil.py`：新增 `FIGURE_LABEL`、`FIGURE_ID`、`CHAPTER_FIGURE`、`APPENDIX_FIGURE`
   与 `figure_caption()`、`figure_ids()`；整行正则统一带行尾空白容忍。
2. 六个消费者改为引用共享形状：
   - `audit/captions.py`、`audit/figure_clusters.py`：直接使用整行解析助手；
   - `audit/smart.py`：改用整行助手，引用句式仍用共享图号形状拼接；
   - `audit/readability.py`：前缀判断与整行解析都走助手；
   - `audit/figures.py`：图号与引用句式用共享形状拼装，保留自己的计数口径；
   - `audit/structure.py`：用共享的章号/字母形状分组，保留唯一性与连续性的判定。
3. `audit/structure.py`：`range(1, 13)` 两处改为从 `_config.chapter_numbering()` 汇总章号。
4. 新增用例：图注解析助手（数字/字母/带后缀/行尾空白/非图注行）、章节范围推导（含空配置）。

---

## 3. 验收

| 判据 | 怎么验 |
| --- | --- |
| 图注形状只有一处定义 | `grep -rn '\*\*图 ' src/python/audit` 只剩引用共享助手的调用，不再有自备正则 |
| 门禁结论不变 | `make.py check` 全绿；六个门禁的输出与整改前逐条相同 |
| 章节范围由配置决定 | 构造 3 章夹具，`structure.py` 只统计这 3 章；编号数组为空时不崩溃 |
| 用例覆盖 | 快档用例全绿，且新增用例覆盖上述分支 |

---

## 4. 回退

单次提交，回退即恢复六个脚本与 `_mdutil.py`；配置与手稿未改动，不需要数据回退。
