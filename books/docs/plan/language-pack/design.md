| 术语 | 在此处的含义 |
| --- | --- |
| 语言包 | `data/language/<code>.json`，一本书一套：骨架名、提示前缀、图注与引用句式、术语行 |

| 产物标识 | `book.toml [book] merged_name`，决定 `dist/` 里的文件名 |

## 1. 目标与非目标

**目标**：同一套工具链与同一套门禁能产出第二语种的同一本书——章节数、图号集合、
术语条目与中文版一一对应；语言差异只体现在语言包与正文文本里，不体现在脚本里。

**非目标**：不做机器翻译（正文由人写）；不做多书合一构建（一本一个根目录）；
不在同一本书里混排两种语言；不改写作体例本身（`how-to-write.md` 仍按中文定义）。

**硬约束**：缺**字段**必须回退到现行中文取值，不能静默变成空串；非中文语种的**包文件缺失**
则直接失败（不许靠回退伪装成功）；两语种的产物互不覆盖；两语种的图号与章节编号逐条对应。

## 2. 现状事实

**语言包已经在用，但只装了"文案"**：`data/language/zh.json` 现有 `sections`（导读/小结/
延伸思考/延展阅读）、`exercise`（提示/回顾前缀）、`terms`（术语参考行、术语表标题与链接）、
`style`（句末标点、全角标点开关）。读取入口是 `_config.language()`，语种码来自
`BOOK_LANGUAGE` 环境变量（默认 `zh`），`core/scaffold.py` 生成新书时复制 `zh.json` 并只改写 `code`（与 `--lang` 无关）。

**判据与渲染里的中文是散在多个模块的**，语言包只盖住了其中两个：

| 模块 | 写死的点 | 类别 |
| --- | --- | --- |
| `audit/structure.py` | 图号 `**图 N-M:**`、附录 `**图 A-M:**`、跳章引用 `详见第N章`、练习小节 `延伸思考` | 语言取值 |
| `audit/figures.py` | 图号正则与 `如图 X-Y 所示` | 语言取值 |
| `audit/captions.py`、`figure_clusters.py`、`smart.py`、`readability.py` | 图注正则 `**图 N-M:**`（四处各写一份） | 语言取值 |
| `audit/crossrefs.py` | `详见第N章《标题》`（章号与书名号两处） | 语言取值 |
| `audit/exercises.py` | 跳章锚点 `第\d+章`；小节名与前缀已走语言包 | 部分已解耦 |
| `audit/book_quality.py` | 统计 `详见第\d+章` 的引用密度 | 语言取值 |
| `audit/style_rules.py` / `lib/_mdutil.py` | 术语识别与中英空格规则 | 语言取值 |
| `render/to_html.py` | 用 `^# 第\d+章` 定位正文起点（封面与正文的分界） | 语言取值（**静默失败点**） |
| `audit/structure.py` 的必备段落 | 取自 `book.toml [sections]`，每语种一本书各一份 | 配置，不是硬编码 |
| `manuscript/terms.py` | 术语行已走语言包 `terms` 段 | 已解耦 |
| `render/to_html.py` | `<html lang="zh-CN">` 写死 | 语言取值（元数据） |
| `render/to_epub.py` | 元数据 `lang: zh-CN` 与 `--metadata=lang:…` 写死 | 语言取值（元数据） |
| `manuscript/cover.py` | 用 `版本` / `共…·…幅 ASCII` 这类中文锚点回写封面统计 | 语言取值（封面上这些行匹配不到就静默不更新） |


**句子长度锚点已按脚本族区分**：`core/scaffold.py` 的 `PROSE_ANCHORS` 有 `cjk` 与 `latin`
两套，`CJK_LANGS` 决定用哪套。这条思路正是第二语种要沿用的：**同一判据，按语言取参数**。

**语种码只在启动时确定**：`_config.LANGUAGE_CODE` 在模块导入时从 `BOOK_LANGUAGE` 读取，
没有配置键；同一次进程内不可切换。`book.toml` 目前**没有**声明语种的键，因此“构建的是哪个
语种”完全靠环境变量——设计上新增 `[book] language`（默认 `zh`）与访问器 `_config.book_language()`，
并与 `BOOK_LANGUAGE` 做一致性比对。

**证据链只有一个来源**：`merged_name` 决定 `dist/` 文件名；两语种若共用同一个名字，
后构建的会覆盖前一个，因此语种与产物名必须成对声明。

## 3. 三层模型

1. **数据层（语言包）**：所有"随语言变化的词"都在这里，包括图注标签、引用句式、
   必备段落名、练习前后缀、术语行、标点开关。缺字段→回退中文，且回退是可断言的。
2. **判据层（脚本）**：判据只从语言包取词，自身不出现任何语种字面量。语言中性判据
   （计数/唯一/顺序/行数/可解析）完全不动。
3. **产物层（配置）**：`merged_name` 每语种一份；`dist/` 文件名因此天然不冲突。

判据层的分界线是"这条判据在问什么"：问"有没有、几个、是否唯一、顺序对不对"→ 语言中性；
问"这句话写得像不像本语种的图注/引用"→ 语言取值。

## 4. 语言包 schema（目标形态）

| 段 | 字段 | 类型与用途 | 现状 |
| --- | --- | --- | --- |
| — | `_note` | 字符串，说明这个包管什么 | 已有 |
| — | `code` | 字符串，必须与文件名一致（不一致时 `_config` 不会发现） | 已有 |
| `sections` | `guide` / `summary` / `exercises` / `further` | 骨架小节名、必备段落比对 | 已有 |
| `exercise` | `hint_prefix` / `review_prefix` | 练习提示与回顾行前缀 | 已有 |
| `terms` | `reference_line` / `glossary_title` / `glossary_link` | 术语参考行与术语表 | 已有 |
| `style` | `sentence_endings`（字符集合成的字符串）/ `fullwidth_punctuation`（布尔） | 标点与断句规则；拉丁文语种通常只保留句点 | 已有 |
| `figures` | `label`（如"图"） | 图注与图号的前缀 | **新增** |
| `figures` | `citation_template` | 行内引用句式（含图号占位） | **新增** |
| `crossref` | `template` | 跨章引用句式（含章号占位） | **新增** |
| `prose` | `script_family` | `cjk` 或 `latin`，决定句子长度锚点 | **新增** |

两条规则：字段只增不改（老包照样能跑，靠回退）；模板用占位符（如 `{n}`、`{m}`），
不把正则写进数据——数据里只放**句式**，正则由脚本按下标拼装，避免把可执行文本放进配置。

**分工**：语言包只装“随语言变化的词与句式”；内容阈值与词表（如 `style.json [captions]`
的 `leading_verbs`、`min_chars`、`max_chars`）留在 `style.json`，因为它是“每语种一本书
各一份”的内容规则，不是工具常量。两处不重复同一张词表。

**缺失时的回退形状**：语言包文件不存在时，`_config.language()` 只合成 `sections` 段
（取 `book.toml [sections]` 的字符串值，其余段为空），于是图注、引用、正文起点会退回脚本里的
默认字面量。因此完整性检查必须区分两种情况：
中文包缺失字段允许回退；**非中文语种的包文件本身缺失就视为失败**，不能靠回退跑下去。

## 5. 哪些判据必须语言中性

这些判据在任何语种下答案都相同，改语言不该影响它们，也不该给它们加语种分支：

- 章节数与章节顺序、图号集合与唯一性、图注条数、练习条数下限；
- 索引条目与其指向的章节、术语条目与其章节引用、跨章引用的目标是否存在；
- 合并稿行数与章节合计是否一致、围栏配对、标题层级连续性；
- 源码坐标可解析、代码摘录与源码一致。

**一项与语言无关但必须同时处理的前提**：`structure.py` 的逐章统计以 12 章为前提
（`range(1, 13)` 两处）。它与语言无关，却与"这本书"绑定：章数不同时多出的章会被静默忽略。
设计上要求章节范围从 `book.toml` 的章节编号推导。

**等价性判据**（新增，也属语言中性）：第二语种的章节数、图号集合、术语条目数、
索引条目数必须与第一语种逐一相等；不等即失败，并指出差异项。

判据要知道“另一语种在哪”，因此需要一条显式指针（配置里的“对照书”），不能扫描目录猜：
指针缺失或指向不存在的书时，判据输出“单语种，跳过”而不是报错。

**阈值与等价性分开看**：等价性比较的是“结构数量”（章节、图号、术语、索引条目），
**不比较阈值取值**——`style.json` / `base.json` 属于每本书自己的内容规则，第二语种可以有
不同的长度区间与词表；但两书若引用同一套等价判据，阈值本身应当同源同值，否则差异会被
误读成内容缺失。

## 6. 产物与命名

- `[book] merged_name` 每个语种一份值，`dist/` 里因此是两份独立产物（`.md`/`.html`/`.pdf`/`.epub`）。
- **一语种一本书根目录**：语言包按 `BOOK_LANGUAGE` 选择，`book.toml` 声明该书语种；
  两者不一致即构建失败。不做“同一根目录下双语切换”，也不做双语并行构建。
- 因为一本书只有一个语种，`dist/` 冲突只可能来自“两个语种共用一个根目录”——那本身违反上一条，
  因此不为它额外造检测：不变量成立时冲突不存在。
- 两语种靠“对照书指针”互相看见（见 §5），指针写在配置里，脚本不搜目录。

## 7. 风险与静默失败点

1. **缺字段回退成中文**：第二语种构建"成功"，但图注仍是"图"、引用仍是"详见第…章"，
   门禁全绿。→ 判据：语言包完整性检查（第二语种必须显式声明 `figures`/`crossref`/`prose`
   段），并有一条"回退发生时会报出语种与字段名"的输出。
2. **等价性漂移**：翻译时多删一张图、少写一条术语，两语种就对不上，而单看第二语种是绿的。
   → 判据：§5 的等价性检查。
3. **产物互相覆盖**：`merged_name` 相同即覆盖。→ 判据：构建前比对产物名与当前语种，
   同名而语种不同即失败。
4. **标点规则误用**：把中文的全角标点与句末规则套到拉丁文本上，判据会大面积误报。
   → 由 `prose.script_family` 决定锚点与标点规则，不靠猜。
5. **锚点与 slug**：标题语言不同 → 锚点不同，索引与跨章引用必须按各自语种解析；
   索引的"条目指向章节"判据保持语言中性。
6. **正文起点识别**：`render/to_html.py` 用 `^# 第\d+章` 找正文开始位置。第二语种标题不是这个
   形状，封面与正文的分界就会错位（封面被当正文渲染），而门禁只看合并 markdown，全绿。
   → 判据：起点模式取自语言包；找不到起点即构建失败，而不是默认从头渲染。
7. **新书拿到的是中文包**：`core/scaffold.py` 的 `_language_pack(code)` 无论 `--lang` 是什么，
   都把 `zh.json` 的内容复制过去、只改 `code`。于是第二语种的新书带着中文骨架跑起来，
   看起来“构建成功”。→ 修正：按请求的语种复制对应语言包；目标语种的包不存在即失败，
   不得用中文包顶替。

## 8. 门禁影响矩阵

| 脚本 | 影响 | 处理 |
| --- | --- | --- |
| `structure.py` | 图号/引用/练习小节硬编码 | 改为从语言包取词；缺失回退 |
| `figures.py` | 图号与引用句式硬编码 | 同上 |
| `figure_clusters.py` / `smart.py` / `readability.py` | 图注正则各写一份 | 统一从语言包取图注前缀，不各写一份 |
| `captions.py` | 图注前缀硬编码；词表与区间在 `style.json` | 前缀取自语言包；第二语种带自己的词表与长度区间 |
| `crossrefs.py` | 引用句式硬编码（含书名号） | 句式取自语言包，章号与标题两个占位符 |
| `book_quality.py` | 引用密度统计硬编码；由 `scorecard` 调用，属报告面 | 取词同 `crossrefs`；不作门禁，只进报告 |
| `style_rules.py` / `_mdutil.py` | 术语识别与中英空格规则 | 术语模板取自语言包；中英空格只对 CJK 生效 |
| `render/to_html.py` | 正文起点靠 `^# 第\d+章` | 起点模式取自语言包；找不到起点即构建失败 |
| `render/to_epub.py` | 元数据语言写死 | 语言取自语言包（`code`） |
| `manuscript/cover.py` | 封面统计用中文锚点匹配 | 锚点句式取自语言包；匹配不到即报告而不是静默跳过 |
| `exercises.py` | 标题与前后缀 | 标题取自语言包（已部分实现） |
| `terms.py` / `index.py` | 术语与索引文案 | 文案取自语言包，结构判据不动 |
| 新增 | 语言包完整性 + 双语等价性 | 一条独立判据（见 §5、§7），等价性靠“对照书指针” |
| 新增 | 语种一致性 | `BOOK_LANGUAGE` 与 `book.toml` 声明的语种不一致即失败 |

## 9. 不做什么

- 不做机器翻译，也不做"翻译记忆"：正文与第二语种手稿都由人写。
- 不在一本书里混排两种语言，也不做语言切换的增量构建。
- 不为第二语种改写作体例：`how-to-write.md` 仍按中文定义，第二语种只借用结构判据。
- 不把正则表达式写进语言包：包里只有句式与词，拼接逻辑留在脚本里。
- 不让语言包承担"内容"：图注、术语、索引条目本身仍是手稿的一部分。

## 10. 降级与回滚

- 语言包**字段**缺失：回退到现行中文取值并打印警告，不阻断构建（老包才能继续用）。
- 语言包**文件**缺失：仅当语种为中文时允许（合成 `sections` 回退）；其他语种直接失败。
- 第二语种判据过严导致无法推进：把该判据降为 advisory（保留输出、不改退出码），
  并把口径写进 `testplan.md`，而不是删掉判据。
- 整个第二语种回退：删掉第二语种的语言包与手稿目录即可；判据改造对中文版无行为变化，
  因此不需要回退脚本改动。
