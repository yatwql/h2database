## [0.3-dev] - 开发中（未发布）

### 变更

- **附录 A 增「三条路径对照」表（plan-13 阶段 3）**：把读路径、写—提交路径、启动路径的起点、经过的关键层、一致性来源与失败后可恢复点并排，读者不必回读三节就能看出分工；正文论述未改。
- **ch11-12 补一条 COW 摘录**：在 12.1.1 的写时复制论述后插入 `Page.copy()`（382-387），该章坐标密度 0.4 → 0.8/千行；剩余最薄的是 ch6-2（2.1）与本章本身，继续按同样方式补。
- **补摘录把密度抬起来（plan-20 阶段 3 续）**：ch6-3 补 3 条（策略入口、全排列循环、遗传重启）、ch6-2 补 1 条（FreeSpaceBitSet 释放），坐标密度 ch6-3 **0.3 → 1.4**/千行、ch6-2 **1.9 → 2.1**；`evidence` 的坐标下限随最弱章（ch11-12，0.4）从 0.3 抬到 0.4。
- **摘录存量清零（plan-20 阶段 3）**：16 处引用错行或手改代码的摘录全部按源码重新生成，长跨度以 `// ...` 省略、超宽行以省略代替换行；`excerpt.py --check` 归零，`content-depth` 基线 78 → 63。随后实测：坐标总数仍是 232、ch9-10 仍是 2.9/千行——**修的是可信度，不是密度**；密度要靠给 ch6-2/ch6-3 补摘录，这两章目前 1.9 与 0.3/千行。
- **内容活的自我校验写成规程**：`how-to-write.md` §7.3 给出三条可被门禁证明的约束（摘录先行、断言带据、数字取事实）、一条操作纪律（一次一改、无改善回退）与两条门禁测不到时的办法（抽样复核、独立评审）；plan-20 阶段 3 定为「逐段五步法」。同节把重复的 7.1 编号纠正为 7.2。
- **P2 收口（代码部分）**：① `evidence` 判据开判——坐标 0.3/千行、符号 8/千行（取当前最弱章作棘轮，段落依据率仍只报告，因为附录本来没有正文）；② 快照 `list` 支持 `--book/--source` 过滤，无匹配时说明筛了什么；③ LLM 提示语配置化：`book.toml [llm.prompts]` → 语言包 `prompts` → 内置英文兜底，占位符填值失败时原样保留；④ 摘录生成器（plan-20 阶段 2）已在前一条提交。
- **摘录生成器（plan-20 阶段 2）**：`manuscript/excerpt.py` 三件事——按 `--file/--lines` 打印标准摘录块、`--check` 按与门禁相同的规则复核手稿、`--repair` 按源码重定位出错行的出处并补 `// ...`（不改代码）。阶段 3 的 16 处存量仍需人工确认：批量重定位会把「展示行不在该文件里」的情况改错，已回退。
- **摘录判据按范围核对（plan-20 阶段 1）**：头行 `文件:起-止` 现在逐行核对，允许 `// ...` 标注省略（按顺序子序列判定），行尾 `// 说明` 不算改动。一次暴露 **16 处**引用错行或省略未标注的摘录（集中在第 9–10 章），已进基线待修。`book.toml` 与手稿未改。
- **依据密度按章可测（plan-19 阶段 1）**：新增 `audit/evidence.py`，每章给出坐标/千行、符号/千行与段落依据率；阈值在 `style.json [evidence]`，当前全为 0 即只报数。首次实测：最厚的是附录 A（21.5 坐标/千行、79 符号/千行、47% 段落有依据）与 ch4-5（21.5、36.3、20%）；最薄的是 ch6-3（0.3、8.2、4%）与 ch6-2（1.9、9.4、4%）；ch7 与 ch11-12 的段落依据率尚可（43%、36%）但坐标密度只有 2.7 与 0.4。
- **强断言必须有依据（plan-15 阶段 1）**：新增判据 `audit/claims.py`——正文里的强断言（总是/绝不/唯一/保证了…）若句内没有 `文件:行号`、`Class.method(` 或反引号类名，按章计入「未带依据」；先量后治：本书记下 35 条作基线，计数只许降不许升。图注导语、表格与代码块不算正文。断言词表在 `style.json [claims].markers`，书可覆盖。
- **坐标密度立项（plan-19）**：本书每千行仅 5 处坐标、25 处符号引用、84% 的实质段落无可回溯依据；按章设置密度下限的迭代已立项，先只读量化、再补依据、最后开判。
