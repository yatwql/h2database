# DESIGN-WEB.md — 网页控制台契约

> 软件：bookwright — 源码分析成书工具 v0.1
> 版本：v0.1-dev
> 定位：**网页控制台（`app/web.py`）的唯一判据**。共有规则见 `DESIGN.md`；本文规定
> 页面与接口的形状。它服务"在另一台机器上点几下就跑一次动作"，不是产品官网，
> 也不是成书产物的一部分。

## 1. 边界

网页控制台是三个渠道之一，与终端、命令行共用同一份动作表（`core/actions.py`）。
它只做三件事：把动作列成按钮、接收一次点击、把结果原样显示。因此它**不得**：

- 自己判断动作是否可用、是否该确认、参数是否合法——这些属于领域层；
- 导入 `ingest/`、`manuscript/`、`audit/`、`render/`，或驱动编排脚本；
- 持有业务规则、写文件、起子进程。

## 2. 绑定与安全

- 默认绑定 `127.0.0.1`：动作会写仓库，不能默认暴露到网络上。
  需要远程访问时由使用者显式指定 `--host`，并自行承担网络侧防护。
- 只允许 GET 与 POST；未知路径返回 404，未知动作由领域层返回失败码，页面不做拦截。

## 3. 路由与响应形状

| 方法 | 路径 | 语义 | 响应 |
| --- | --- | --- | --- |
| GET | `/`、`/index.html` | 单页控制台 | `text/html`，动作表内联进页面 |
| GET | `/api/status` | 书籍 + 配置 + LLM 状态 | `{"code": 0, "output": "<文本>"}` |
| POST | `/api/run` | 执行一个动作 | `{"code": N, "output": "<文本>"}` |
| 其他 | 任意 | 未定义 | 404 `not found` |
| POST | `/api/run` 体非 JSON | 用法错误 | 400 `{"code": 2, "output": "invalid JSON"}` |

响应契约的三条硬规则：

1. **`code` 即退出码**：`0` 成功、`1` 动作失败、`2` 用法或环境错误。页面不得改写码值。
2. **`output` 即原样输出**：动作打印什么就返回什么，不截断、不重排、不加解读。
3. **HTTP 状态与 `code` 分离**：请求本身被正确处理就返回 200，即使动作失败；
   只有请求无法处理（404/400）才用非 200。

## 4. 页面结构

单页，从上到下四段：

| 段 | 内容 |
| --- | --- |
| 标题 | 软件名与版本（来自配置），不复述书名 |
| 动作区 | 每个动作一个按钮；悬停显示动作说明；顺序与动作表一致 |
| 参数区 | 仅 `llm-ask` 需要提示词输入框 |
| 输出区 | 等宽、可换行、保留完整文本；执行中先显示"运行 <动作> …"，结束后显示 `[退出码 N]` 与输出 |

页面自身不含状态机、不含列表推导之外的逻辑、不引入任何前端框架或构建步骤：
一个 `<script>` 负责按钮渲染与一次 `fetch`。

## 5. 状态呈现

- 执行中：输出区显示进行中的动作名，按钮不禁用（动作可重复触发，由使用者判断）。
- 成功：`[退出码 0]` + 输出原文。
- 失败：`[退出码 N]` + 输出原文；颜色的语义与终端一致（见 `DESIGN.md` §3），
  但不额外生成"友好错误"——原文已经包含文件名与行号。
- 网络或服务不可达：由浏览器原生表现，页面不编造替代文案。

## 6. 允许与禁止

允许：新增动作按钮（动作表变化后自动出现）、调整布局与间距、提升可读性。
禁止：为单个动作写特例逻辑、在页面里做参数校验、新增第二个强调色、引入 JS 框架、
把书名或统计数字写进页面模板（它们属于配置与运行时数据）。

## 7. 验收

| 判据 | 由谁守 |
| --- | --- |
| `/` 返回 200 且含软件名与全部动作按钮 | `src/test/test_app_web.py` |
| `/api/status` 与 `/api/run` 的 JSON 形状与 `code` 语义 | 同上 |
| 非 JSON 请求体返回 400 且 `code: 2` | 同上 |
| 未知路径 404 | 同上 |
| 页面不含业务逻辑、无子进程与写文件 | `audit/check_architecture.py`（渠道纯净） |
